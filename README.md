# OhmConverter — Resistance Unit Converter

A simple Python utility to convert electrical resistance values between standard units: Ohm (Ω), kilohm (kΩ) and 
megaohm (MΩ).

Built as a practical scripting exercise during research work in printed electronics and materials characterisation.

## Usage

```python
python OhmConverter/main.py
```

## Tech stack

- Python 3
